# CineApp: descargas

Aquí solo están los instaladores de la última versión de CineApp. La propia app los usa para actualizarse
sola. El código está en otro repositorio.

| Dispositivo | Archivo |
|---|---|
| Windows | `CineApp-Windows.exe` |
| Fire TV (Stick y Cube) | `CineApp-FireTV.apk` |
| Móvil / tablet Android | `CineApp-Android.apk` |

Fire TV, primera vez: instala la app **Downloader**, activa "Instalar apps desconocidas" para Downloader y escribe el
código **9618279** (o la dirección `https://raw.githubusercontent.com/tlosrod672/cineapp-releases/main/CineApp-FireTV.apk`).

A partir de ahí, CineApp avisa sola cuando hay versión nueva.
